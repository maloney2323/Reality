# Reality: Foundational Governed Self-Improvement Architecture v1

**Status:** Kernel and bounded driver created in an isolated branch for regression review. Not a deployed autonomous engineer, not an owner authorization, not original job #143 completion, and not evidence of superintelligence.

## Purpose

Give underlying models an evidence-grounded, durable, governed self-improvement loop. Model output is a proposal, not truth, approval, capability installation, or completed work. Reality owns goal continuity, evidence, independent verification, error budgets, promotion boundaries, resumption and final settlement.

## One central spine

| Stage | Permitted actor | Required proof | Forbidden inference |
|---|---|---|---|
| Confirm missing capability | Independent observer | Original owner goal, job, frozen failures | Model assertion creates gap |
| Design candidate | Replaceable model | Verified gap and verification plan | Generated code can edit constitution or grant power |
| Verify | Independent no-secret sandbox | Exact generated artifact hash, frozen regression and independent test receipt | Test pass equals installation |
| Correct | Replaceable model | Exact failed test evidence and bounded attempt count | Infinite retries or hallucinated tools |
| Approve | Authenticated human | Exact source, work, goal, one-use grant | Chat text or AI opinion equals authorization |
| Register | Privileged trusted adapter | Database-atomic write and independent readback | Approval alone installs capability |
| Resume | Original job executor | Actual re-observation of registered capability and original work | Synthetic job substituted for original |
| Settle | Independent verifier and Continuity | Linked durable verified original-job receipt | Model declaration equals business completion |

### Implementation

- src/reality-governed-self-improvement-spine-v1.0.js: source-linked immutable goal/work identity; independent provider-attested evidence boundary; finite model repair budget; deterministic failure taxonomy; append-only SHA-linked checkpoint integrity; verified stages for owner approval, registration, actual resumption and settlement.
- src/reality-governed-self-improvement-driver-v1.0.js: replaceable model generator plus trusted independent observation, isolated sandbox, readback and checkpoint adapters. Stops at approval, and requires provider-backed checkpoint reads on every stage.
- test/reality-governed-self-improvement-spine-v1.0.test.js: adversarial tests for forged approval, scope drift, synthetic test success, kernel edits, missing capabilities, stale stage transitions, tampering, retries, registry and settlement.

The implementation reuses existing Reality autonomous capability loop and self-question engine. It does NOT replace the existing Universe, GoalState authority contracts, Continuity, access boundary, reservation store, or constitutional learning.

### Trust boundary

Untrusted: all model input/output, prompt instructions, user-facing chat strings, arbitrary client JSON, apparent success logs and model-generated receipts. Trusted: only actual server-side adapters which independently verify owner session, goal epoch, provider source, sandbox result, explicit approval, one-time reservation, registry record, executor outcome and ledger settlement. These adapters must not come from browser fields or model-generated code.

The SHA-linked in-memory journal protects checkpoint integrity only when the trusted adapter durably stores and independently reads back the state. It does not replace database atomicity or cryptographically signed external attestations.

### Known limitation

The kernel is not yet connected as the live scheduler or personal chat execution path. Existing chat remains read-only. The driver needs production-quality adapters to reconstruct the active goal and original job, run model synthesis, execute a real isolated sandbox, persist state into Continuity and use exact owner approval. Those connections must be independently tested before deployment. We must not classify an architecture test or code PR as 7/7 job completion.

### Live acceptance test

1. Reality recovers the owner-authenticated goal and original work #143.
2. Reality observes the missing capability and independently proves that gap.
3. Its model generates a bounded code candidate.
4. A no-secret sandbox independently tests it and returns exact failure evidence.
5. The model corrects until verification succeeds or an evidenced blocker halts it.
6. Owner explicitly authorizes an exact promotion; model cannot supply approval.
7. Trusted adapter writes and reads back the exact capability and original goal.
8. Reality resumes the same original work and verifies the actual outcome.
9. Continuity durably settles with receipt and reports only observed customer value.
10. No ChatGPT-written source repair during this trial. No production installation without separate authorization.

**No 7/7 claim without all linked live receipts.**
