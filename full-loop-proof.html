What's proven — and what's not

The positive case requires independently reconstructed sandbox state before it can commit learning or resume. Denied authorization must block execution. Withheld verification must block completion.

The proof does not yet cover a real customer connector, independent external source, generated code acquisition, production merge, human supervision time, or an unattended real deployment. Those must be independently tested next.
